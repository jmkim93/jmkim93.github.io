Topologically Protected All-Optical Memory

Seou Choi, Jungmin Kim, Jeonghun Kwak, Namkyoo Park & Sunkyu Yu

Advanced Electronic Materials 8, 2200579 (2022)

Publisher pageRead PDF

Optical memory needs two properties that can conflict: a state must resist small disturbances, yet remain easy to switch deliberately. This paper addresses both through the dynamics of three coupled resonators.

Store the bit in a stable optical state

The proposed photonic molecule contains a neutral resonator between gain and loss resonators. The outer resonators have saturable responses, so their effective amplification and absorption depend on the optical intensity.

For appropriate parameters, the system supports coexisting stable oscillation-quenching states. These states have different intensity distributions across the resonators and can represent the two values of a memory bit.

Why the state can survive a disturbance

The protection is described through the topology of dynamical trajectories. Nearby initial conditions converge toward a stable state rather than causing the stored intensity pattern to wander indefinitely. The analysis identifies parameter regions where two suitable states coexist.

This is a statement about the nonlinear system’s dynamics, rather than the use of a conventional topological edge channel. Its stability analysis provides criteria for choosing a memory element and understanding the boundaries between stored states.

Switching without a phase reference

To write or erase the bit, optical control moves the system into the other state’s basin of attraction. The paper models modulation through weakly coupled waveguides and numerically tests switching in both directions.

The demonstrated switching can be insensitive to the control light’s global phase. It still uses designed local control fields; phase-insensitive switching does not mean arbitrary illumination will write the desired state.

Together, the stability and switching calculations describe a candidate optical memory building block. They do not establish a fabricated memory array, but identify how saturable gain and loss can combine retention, readout, and deliberate optical state transitions.
